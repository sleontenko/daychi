# Безопасность

Этот снимок не содержит закрытого видеокорпуса, транскриптов, пользовательских
баз, токенов устройств, Telegram-сессий, `.env.local`, APNs private key, Apple
профилей и подписанных архивов. Не добавлять их даже в приватный репозиторий.

В `EXPO_PUBLIC_*` разрешены только несекретные значения: они попадают в приложение.
Team ID, Bundle ID и адрес публичного расписания не являются секретными ключами.

`practice_api.schedule_app` публикует расписание школы. `practice_api.app` —
отдельный API закрытого корпуса: не открывать в интернет без авторизации и
согласованной политики доступа. Старые серверные уведомления используют отдельную
базу устройств и авторизацию; build 3 использует локальные уведомления iOS.

Перед каждым push проверять staged diff и список файлов. Перед выпуском
проверять endpoint, подпись и entitlement в итоговом архиве. Не отключать TLS
валидацию ради доступности. Не писать токены, исходные сообщения Telegram или
ключи в логи и отчёты тестов.

Зависимости и сторонние dSYM имеют известные follow-up задачи в ROADMAP;
наличие этого файла не означает завершённый security audit.
