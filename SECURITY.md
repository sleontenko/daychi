# Безопасность

Сообщения об уязвимостях: [dev@mypraxis.ai](mailto:dev@mypraxis.ai).
Не публикуйте секреты или персональные данные в issue.

- Вики, Zoom и административные API требуют авторизации.
  Старый corpus API `practice_api.app` нельзя открывать публично.
- Не коммитьте рабочие базы, исходные записи, расшифровки, приглашения, сессии,
  пароли, ключи подписи и локальные `.env`.
- Клиентские `EXPO_PUBLIC_*` доступны пользователю; секреты храните на сервере.
- Не отключайте TLS-проверку. Для разработки используйте синтетические fixtures.
- Перед push запускайте `python3 scripts/check_repository.py --staged`.
  Проверка известных признаков секретов не заменяет просмотр diff.
