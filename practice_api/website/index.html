Прямое скачивание, не Google Play. Телефон может попросить разрешить установку из браузера.

Приглашение в TestFlight нужно только для установки. Вики и Zoom открываются после одобрения заявки.

Доступ к вики и Zoom

Подайте заявку в приложении — организатор откроет доступ этому телефону.

  1. 1
    Установите Дейчи.
  2. 2
    Во вкладке «Вики» нажмите «Запросить доступ».
  3. 3
    Укажите имя и фамилию, при желании Telegram, и отправьте заявку.
  4. После одобрения откройте приложение — вики и Zoom станут доступны без кода.
  • Статус заявки проверяется при открытии приложения. Уведомления об одобрении нет.
  • Потом доступ остаётся, пока его не отзовут или вы не выйдете.
  • Для второго телефона нужно отдельное одобрение.
  • Уже есть персональная ссылка? Откройте её после установки на том же телефоне или выберите «У меня есть персональное приглашение» в форме заявки.
  • Этот сайт не принимает и не проверяет коды — он только объясняет.
