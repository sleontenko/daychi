Владелец поручил переименовать Quiet Practice в daychi (Дейчи) и загрузить
последние материалы для коллабораторов. Каноническое написание:
**Daychi**, репозиторий/slug **daychi**, русское имя **Дейчи**.

- README и заголовки текущих инструкций/продукта; добавлены CONTRIBUTING,
  архитектура и навигатор документации.

Новая версия приложения и deploy этим переименованием не выпускаются.

материалами; скриншот группы TestFlight с персональными данными.

на приватные evidence могут отсутствовать в clone; не удаляйте файлы владельца.
Автоматический scan проверяет текст/архивы, но не заменяет ручную проверку
картинок и не является полным security audit.
