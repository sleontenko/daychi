# Название и совместимость

Название проекта: **Daychi / Дейчи**. Репозиторий —
[sleontenko/daychi](https://github.com/sleontenko/daychi).
Пакеты: `daychi-app`, `daychi-wiki-graph`, `daychi`; Expo slug — `daychi`.

Для совместимости сохранены:

- iOS/Android ID `ai.mypraxis.quietpractice`;
- URL-схема `quietpractice`;
- ключи локального хранения и существующие ID материалов;
- `DAYCHEE_*`, API-маршруты, модули и deploy-пути.

Эти идентификаторы не меняются обычным переименованием: они связаны
с установленными приложениями, сессиями, приглашениями и закладками.
Исторические release tags и дизайн-архивы сохраняются.
