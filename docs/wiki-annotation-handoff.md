## Приватный пакет

Каталог `data/wiki-audit/2026-09-24/batch-01/` исключён из Git правилом `data/`.

- `annotations.md` — чтение и редактура всей партии.
- `annotations.json` — структурированные тексты и доказательства.
- `report.md` — покрытие, спорные места и границы проверки.
- `build_batch.py` — локальная воспроизводимая сборка редакции 1 из вручную
  написанных аннотаций; не запускать поверх последующих редакторских правок.
- `validate_batch.py` — проверка ID, хешей, структуры и точных фрагментов SRT.

Каждая запись сохраняет `material_id` текущей карточки, заголовок и категорию
индекса, `revision`, `language`, `annotation`, отдельные предложения,
`source.resource_id`, точный метод сопоставления, пути и SHA-256 обоих источников.
`evidence` связывает номер предложения (с 1) с интервалами в секундах и точными
репликами SRT, включая ID реплики. `issues` содержит редакционные замечания.
`glossary_candidates` содержит только исходное написание, фрагменты и вопросы,
без придуманных определений и без одобрения.

Разметка SRT не проверена по видео. Повторяющиеся строки субтитров сохранены
для трассировки; число реплик не равно числу независимых доказательств.
Последняя метка SRT не считается проверенной длительностью оригинала.

## Условие передачи приложению

Предлагаемый контракт версии 1 для последующей реализации другой задачей:

```json
{
  "schema_version": 1,
  "annotations": [
    {
      "material_id": "EXISTING_CATALOG_ID",
      "language": "ru",
      "revision": 1,
      "annotation": "Одобренный текст из 2–4 предложений.",
      "provenance": {
        "provider": "youtube",
        "resource_id": "EXACT_VIDEO_ID",
        "txt_sha256": "SHA256_HEX",
        "srt_sha256": "SHA256_HEX"
      },
      "review": {
        "status": "approved",
        "approved_by": "EDITOR_ID",
        "approved_at": "ISO8601_TIMESTAMP"
      }
    }
  ]
}
```

Это условный пример, не готовая аннотация. Экспорт пока не создан: одобрений нет.
Передача должна выполняться локально по следующим правилам:

1. Редактор сверяет содержание и существенные оговорки с записью; преподаватель
   проверяет спорную терминологию. Фиксируются результат просмотра и одобрение
   именно данной редакции текста, имя/ID ответственного и дата. Автоматическая
   проверка структуры и повторное чтение тем же агентом одобрением не являются.
2. Экспорт допускает только `approved` с непустыми `approved_by` и `approved_at`.
   `needs_editorial_review`, отклонённые и отозванные записи не экспортируются.
   Изменение текста или хеша источника сбрасывает одобрение и повышает редакцию.
3. При импорте обязательны совпадения стабильного `material_id` и точного ID
   ресурса с актуальным каталогом; дубли ID, неизвестные карточки, несовпадения,
   устаревшая редакция и неполные одобрения блокируют импорт. Заголовок не ключ.
   Повторный импорт той же редакции допустим только с тем же содержимым.
4. Аннотация — отдельное поле, не перезапись заголовка, категории, source URL или
   прежнего описания. Отсутствие одобренного текста означает отсутствие нового
   поля; интерфейс не должен выдавать заголовок за подготовленную аннотацию.
5. Локальные пути, исходные цитаты, спорные термины и редакторская переписка
   остаются в приватном пакете. Словарь передаётся отдельным одобренным набором;
   эти 12 вопросов в словарь автоматически не попадают.
6. Для отзыва импортированной аннотации нужен явный список `material_id` с
   отзываемой редакцией; отсутствие записи в следующей партии не означает
   удаление. Хранение и реализацию отзыва определяет задача приложения.

Формат одобрения содержимого не меняет правила доступа к частному корпусу:
никаких внешних загрузок, публичных веб-экспортов или расширения распространения.
Способ защищённой доставки определяет задача приложения. Старые 14 карточек
NotebookLM сюда не включены: точных совпадений с каталогом у них не найдено.
