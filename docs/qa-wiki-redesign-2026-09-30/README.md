## Даты и recent

`source_timestamp_ms` индекса — исходная дата публикации, не дата добавления в вики.
Таблица identities не хранит created_at, поэтому историческую дату добавления
нельзя восстановить. ContentStore хранит реальное время обновления конспекта
в `content.updated` (Unix seconds), его можно показать в «Обновления конспектов».
Для новых поступлений требуется учитывать first_seen/added_at с момента запуска
учёта, без присвоения сегодняшней даты всему старому архиву. Кандидат должен
различать эти даты; старые записи могут иметь честную метку «дата добавления неизвестна».
