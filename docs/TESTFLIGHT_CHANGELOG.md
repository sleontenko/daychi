# Журнал TestFlight

Приложение: **Тихая практика**, `ai.mypraxis.quietpractice`.
Версия приложения и номер сборки — разные поля: `1.0.0 (4)`.
Записи не переписываются задним числом: уточнения добавляются с датой.
Git snapshot/tag фиксирует исходники, но не заменяет архив и статус Apple.

## Правило выпуска

1. Проверить git status; включить только относящиеся к версии изменения.
2. Заполнить запись и прогнать проверки. Отдельно указать simulator/real device.
3. Увеличить buildNumber, подготовить архив; сверить bundle ID, team, build и URL.
4. Получить разрешение на выпуск, загрузить и дождаться обработки Apple.
5. Назначить существующей группе, проверить Testing, сохранить What to Test.
6. Зафиксировать commit и тег `testflight/ios-VERSION-BUILD`, добавить результат
   проверки на телефоне позже. Не обещать доставку только по успешной загрузке.
