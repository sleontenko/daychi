## Время и оценки

Последние две ASR-партии: 6 записей, 146,2 мин исходного аудио.
Сумма inference основных/повторных проходов — 679,15 с (11,3 мин),
без скачивания, VAD, загрузки моделей, редактуры и QA.
Выборка: Apple Silicon M4 Pro / 48 ГБ; не замер всего корпуса.

| На 3 записи по 20–40 мин | Предварительная оценка |
|---|---:|
| ASR с диагностикой | 5–15 мин без скачивания |
| Редактура, отдельная проверка, сборка/QA | 15–40 мин |
| Текстовые токены | 30–70 тыс., не измеренный usage |
| Выборочное слушание | 12–36 мин дополнительно |

Если всем 641 поддерживаемым источникам нужен ASR при средней длительности
20–40 мин: 214–427 ч аудио, 18–54 ч ASR, 54–143 ч редактуры/QA,
6,4–15 млн текстовых токенов. Это условный сценарий; длительности неизвестны.
Платные ASR API не используются; тарифы участников, оборудование и электричество
не включены. Фактический текстовый usage последних партий не измерен.

После каждой партии обновлять выполнено/всего/осталось, следующий объём,
фактическое время и доступный usage. Неизвестные значения не заменять оценками.
