  Сохранились исходные annotations, появились все backlinks и 16 graph edges.

  на production; новая feature flag по умолчанию выключена.
- Проверены fabrication/hash/revision/alias конфликты, атомарный rollback,
  stale hiding и старый replay без восстановления скрытого контента,
  согласованный read snapshot при конкурентной записи, owner session/CSRF/Origin,
  публичный allowlist и выключенные feature/public flags.
- Chrome: список → понятие → урок → понятие → локальный граф; цитатные якоря
  сохраняют route; Back возвращает к источникам. Фильтры структуры и смысловых
  связей работают отдельно; hash сохраняет их. Проверены loading, пустая выдача,
  404, ошибка 503 и успешное «Повторить» после восстановления. Новые страницы
  входят в недавние публикации; обычное название и дата ведут к странице понятия.
- 390×844: overflow отсутствует; Back и номера цитат не меньше 44×44 px.
  Синтетические кадры и сравнение с Notion/Quartz сохранены в
  [дизайн-кандидате](../../design/candidates/wiki-semantics-2026-10-05/README.md).
  Реальная страница с тремя источниками дополнительно просмотрена локально;
  её кадр, batch, proofs, hashes и квитанции остаются вне Git.
