# Zoom в расписании — build 8

2026-09-19: владелец прислал Telegram-расписание с доступом к 18 занятиям недели.
В детали добавлены «Подключение к занятию», выделяемый пароль и «Открыть Zoom».
Блок использует существующие типографику, цвета, отступы и outline-кнопку.
Не показывается для отменённых и завершившихся занятий. При ошибке открытия
показывается сообщение и выделяемая ссылка для ручного перехода.

## Данные

Приватный файл `apps/practice-app/src/features/schedule/generated/zoom.json`
исключён из Git, права 600. Формат массива: `seriesId`, `weekday` (0=понедельник),
`start` (HH:mm), опциональный `end` для согласованного окончания, `url`, `password`. Исходные URL сохранены вместе с query-параметрами.
При подготовке нового checkout нужен этот приватный файл; не публиковать web export.
Как и снимок вики, данные доступны получателям закрытой беты.

Привязка проверяет стабильный ID серии, дату, день недели и начало по
Asia/Jerusalem, независимо от часового пояса устройства и сезонного смещения.
Изменённое время или неизвестный ID не должны открыть комнату другой группы.
Публичный backend и календарные ID не изменены, выбор занятий сохраняется.

## Согласованные исправления времени

На сайте и в присланном Telegram отличаются окончания:
- вторник, веер: сайт 20:00, Telegram 19:30;
- пятница, Основы Дхармы: сайт 13:00, Telegram 13:30;
- суббота, медитация 18:00: сайт 19:30, Telegram 20:00.

Владелец подтвердил приоритет времени Telegram. Три окончания исправляются
после загрузки из любого источника и при восстановлении кэша. ID и начало
сохраняются, повторное применение не меняет результат. Названия остаются с сайта.
Сопоставлены также сокращённые/различающиеся названия, например пятничный цигун
для продвинутых — «Тайцзицигун» сайта в 09:00. Очные занятия сайта сохранены.
