Датированные отчёты описывают проверки на свою дату. Более новый отчёт может
дополнять прежний; не переносите его результат на все состояния или платформы.
Исторический текст «не выпущено» сохраняется, даже когда позднее появился выпуск:
сверяйтесь с последующей записью changelog.
Некоторые evidence-ссылки доступны только в локальном checkout владельца,
поскольку содержат приватные данные. Отчёт сохраняет результаты и ограничения.
