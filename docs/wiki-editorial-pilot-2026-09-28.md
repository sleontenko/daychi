# Редакторский пилот после реального ASR-батча

Продолжение `wiki-real-batch-2026-09-28.md`. Приватные результаты:
`data/wiki-pipeline/2026-09-28/editorial-pilot/` (игнорируется Git).

Подготовлены 4 аннотации по 3 предложения и 8 вопросов для будущего словаря.
Три аннотации точно привязаны к ID и заголовкам существующего каталога;
одна имеет только локальный ID и рабочий заголовок. Пятая запись отложена
как вероятный дубль: исходники не удалены и тождество не утверждено.

Каждое предложение имеет точные цитаты Turbo, индекс сегмента, таймкоды
исходной записи, SHA-256 транскрипта и аудиофрагмента. Использованы выбранные
фрагменты вне очереди спорных мест, а не сплошная редактура полного занятия.
Тексты написаны агентом по этим фрагментам; платные API не вызывались.
Неустойчивая терминология не нормализована догадками. Вопросы для словаря
не считаются определениями. Все аннотации — `needs_editorial_review`,
одобренных текстов 0; публикации и изменений приложения нет.

`scripts/wiki_asr_gate.py` добавляет независимый механический фильтр:
пустой ответ, `<unk>`, лимит генерации, 8 последовательных повторов фразы
из 1–8 слов, темп свыше 5 слов/с. Из 526 ответов (514 основных и 12 Qwen-проб)
помечены 22. Исходные ответы сохранены; флаги записаны отдельно и учитываются
сборщиком этого редакторского пилота. Фильтр пока не встроен в сами ASR-раннеры.
Он не заменяет прежнюю очередь из 53 спорных фрагментов и не измеряет точность.
Отсутствие флагов не даёт редакционного одобрения.

Проверка: 12 pytest-тестов PASS (индекс, метрики ASR, VAD-окна, новый фильтр),
py_compile PASS. Приватный `validate.py`: 98 точных связей с цитатами,
10 хешей аудиофрагментов, хеши транскриптов, соответствие каталогу и статусы PASS.
Прослушивания аудио и проверки движений по видео не было.

Дальше: встроить фильтр в возобновляемую очередь ASR, отдельно обрабатывать
спорные фрагменты с ограничением длины/времени и расширять редакторскую партию.
Для полноценной статьи потребуется охват всего занятия; эти краткие аннотации
такого охвата не подтверждают. Свежая выгрузка Telegram с MacBook остаётся
отдельной задачей. Правила передачи одобренного текста приложению описаны
в `wiki-annotation-handoff.md`.
