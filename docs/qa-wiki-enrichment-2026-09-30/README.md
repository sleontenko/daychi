## UI и границы QA

Использована существующая композиция читателя из
[QA веб-вики](../qa-wiki-reader-2026-09-30/README.md): кандидат Claude Design
`daychee-web-wiki-2026-09-28-final.zip` и выбранный владельцем граф.
Новые конспект/цитаты используют существующие стили текста и ссылок.

Chrome через CUA, локальный backend с реальным каталогом и синтетическим
локальным входом: «Веер для новичков 38» с черновиком/цитатами, сосед 37 без
аннотации, возврат 37 → 38 → поиск с сохранённым запросом. Проверена ширина
390×844, текст/таймкоды/источники и отсутствие горизонтального переполнения
(documentWidth=innerWidth=390). Отображение на desktop также просмотрено.

Снимки просмотрены в CUA; парные reference/runtime файлы на диске не сохранены.
Это не полная визуальная приёмка и не новый мобильный релиз. Не проверены:
реальные устройства, Android Back, accessibility, полный набор состояний дизайна,
production-читатель после входа. Оформление/навигация каталога и графа не менялись.
