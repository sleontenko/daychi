# Персональный доступ

Расписание доступно без входа. Вики и Zoom требуют действующей сессии.
Основной API работает по HTTPS; настройки задаются через `DAYCHEE_*`
и `EXPO_PUBLIC_DAYCHEE_API_URL`.

## Заявки и приглашения

Новый участник отправляет имя, фамилию и необязательный Telegram.
После решения организатора приложение показывает результат и получает доступ.
Отказ, ожидание, ошибки и отзыв обрабатываются отдельно.

Старые приглашения совместимы: HTTPS-ссылка `/invite#CODE` или короткий код.
Страница не активирует приглашение автоматически; кнопка открывает приложение
через URL-схему. Это не Universal Links / App Links.
Активация одноразовая, срок — 7 дней; сессия действует до выхода или отзыва.
Адрес из вставленной ссылки не меняет API-сервер.

Сервер хранит hashes кодов и токенов. Активации ограничены на IP;
внешние proxy-заголовки принимаются только от доверенного edge.
Клиент защищён от гонок сохранения/отзыва сессии и восстанавливает предыдущий экран.

## Границы

Анонимные закрытые запросы возвращают 401 и no-store.
Административная сессия не равна участнической.
Рабочие базы, коды, токены и Zoom-реквизиты не входят в Git.

Проверки конкретных версий — в [changelog](TESTFLIGHT_CHANGELOG.md)
и [QA заявок](qa-access-requests-2026-09-30/README.md).
