# Дизайн веб-вики

Первая опубликованная версия: 2026-10-01.
Сдержанное оформление Notion, структура чтения Quartz.
Визуальные референсы: `screenshots/reference-*.jpg`.

- Главная: поиск, недавние публикации и разделы.
- Каталог: компактный список, фильтры, понятная пустая выдача.
- Статья: ограниченная ширина чтения, оглавление, источники и связанные материалы.
- Граф: отдельный режим, существующие Sigma/d3 и камера.
- Mobile: одна колонка, доступная навигация, без горизонтального переполнения.
- Спокойные нейтральные поверхности, чёткая типографика, терракотовый акцент.

Исходная дата публикации не равна дате добавления в вики.
Обновление конспекта использует фактический timestamp content store.
Неизвестные даты не восстанавливаются из предположений.

Back сохраняет запрос, фильтр, список/scroll и выбранный узел.
Search input сохраняет DOM-идентичность, курсор и composition.
Черновик, отсутствие описания, ошибка API и отсутствие доступа показываются явно.
Определения и смысловые ссылки добавляются только после редакционной проверки.
