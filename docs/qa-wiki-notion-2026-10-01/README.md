# Веб-вики Notion / Quartz — 1 октября 2026

## Статус и референсы

Локальный кандидат, без deploy и нового TestFlight. Владелец выбрал визуально
только Notion, структуру Quartz. Реализация напрямую с Impeccable 4.4.0;
предыдущий Claude Minimal не является утверждённым источником этой итерации.

Референсы реально открыты в Chrome и сохранены:
[Notion Help](https://www.notion.com/help),
[Quartz](https://quartz.jzhao.xyz/).
Скриншоты: [Notion](screenshots/reference-notion.jpg),
[Quartz](screenshots/reference-quartz.jpg).

Сопоставление: у Notion взяты светлая читательская поверхность, крупный поиск,
типографическая иерархия и спокойные строки. У Quartz — боковая навигация,
содержание статьи и переходы по связям. Это адаптация для библиотеки школы,
а не точная копия: Figtree и терракотовый акцент остаются из Дейчи,
недавние содержат реальный каталог, существующий граф сохранён.

## Оставшиеся границы проверки

Это browser viewport QA, а не реальный iPhone или Android. Android Back,
все камеры/фильтры графа, прямой вход в статью в новой сессии, IME,
offline/auth-expiry и задержанный ответ API не проверены в этой итерации.
Для задержанного ответа код не восстанавливает прокрутку после пользовательского
взаимодействия; реальный сценарий с сетевой задержкой ещё не воспроизведён.
Страница с нулём датированных публикаций не проверена; текущий каталог датирован.
Полная приёмка мобильного приложения и публикация здесь не заявляются.
