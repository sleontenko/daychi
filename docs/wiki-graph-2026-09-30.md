# Граф вики на сайте школы — прототип, 30 сентября 2026

Статус: прототип опубликован на Railway по поручению владельца. Это не утверждённый
дизайн и не замена каталога вики. Адрес: https://daychee-api-production.up.railway.app/wiki/graph

## Решение

Готовые вики-движки (Quartz, Wiki.js, Outline, BookStack, Obsidian Publish) не подходят
как платформа: закрытые материалы нужно отсекать на сервере по персональному доступу,
а данные живут в собственном каталоге с редакторской проверкой. Оставляем свою вики
в `practice_api`, а граф строим на открытых библиотеках: Sigma.js 3 (WebGL) + graphology
для отрисовки и d3-force для живой физики, как в Obsidian.

Кандидат Claude Design «Дейчи - веб-вики.dc.html» рисовал граф как неподвижный SVG
с одноразовой раскладкой (260 итераций, без перетаскивания). На 1 145 записях такой
подход не масштабируется; дизайнер сам отметил, что раскладку нужно считать иначе.

## Что опубликовано

- `GET /wiki/graph` — страница без данных; `/wiki-graph-assets/{graph.js,graph.css}` по allowlist.
  CSP как у сайта плюс `connect-src 'self'`; `noindex`, `no-referrer`.
- `GET /api/wiki/graph` — граф каталога, только с тем же токеном приглашения, что вики и Zoom.
  Без токена 401. Описания, ссылки и Zoom в граф не входят; описание и ссылка на запись
  подгружаются существующим `/api/wiki/materials/{id}` при выборе материала.
- Вход в браузере: код приглашения или ссылка `/invite#…` → `/api/access/redeem-code`.
  Код одноразовый, как в приложении: для браузера нужен отдельный код из админки.
- Связи только детерминированные: структура каталога (раздел → подтема → материал)
  и соседние номера серии в названии одного раздела («Веер для новичков 39 → 40»).
- Возможности: живая физика, перетаскивание узлов, подсветка соседей, подписи по масштабу,
  поиск, фильтр разделов, локальный граф 1–2 шага (до 60 узлов, счётчик «N из M»),
  состояние в адресе, клавиши +/−/0/Esc, 390 px без горизонтальной прокрутки.

Черновые аннотации и термины-кандидаты не опубликованы: у них `needs_editorial_review`,
одобренных 0 (см. [передача аннотаций](wiki-annotation-handoff.md)). Их показывает только
локальный прототип `data/wiki-graph-prototype/graph-prototype.html` (игнорируется Git).
На реальных данных без структуры граф почти пуст: 8 терминов пилота связаны
каждый с одним занятием, поэтому разделы и подтемы оставлены узлами.

## Итерация 2 — исправления после браузерного теста, 30 сентября

По замечанию владельца пройдены все сценарии в Chromium (1280, 1024, 390 px с касаниями).
Найдено и исправлено:

- После перетаскивания узла клик по пустому месту больше не снимал выбор.
- На тач-экранах «залипало» наведение: после выбора соседа подсвечивался прежний узел.
- Материал из поиска в скрытом фильтром разделе выбирался невидимым — теперь раздел включается.
- В локальном графе клик по соседу не перестраивал граф вокруг него; выбранный узел уезжал
  к краю, окружение было приглушено. Теперь центр закреплён, приглушает только наведение,
  узлы разнесены шире, маленький локальный граф подписан целиком.
- Browser Back уводил со страницы. Выбор узла и смена режима — новые записи истории,
  фильтры — замена; Back/Forward восстанавливают выбор, режим и фильтры.
- Касание узла могло «приколоть» его в физике — перетаскивание узлов только мышью.
- Клик по разделу скрывал его. Теперь клик — только этот раздел, повторный — все,
  Shift/⌘ + клик — добавить.
- Список поиска не закрывался по клику мимо.
- Подписи соседей выбранного раздела слипались: камера вписывает узел вместе с соседями,
  при > 12 соседях подписываются только разделы/подтемы.
- В небольших графах (например, «только серии») не было подписей — порог зависит от числа узлов.
- «Узлы без связей» ничего не менял при включённой структуре — теперь неактивен с подсказкой.
- ≤ 900 px: панель узла открывалась ниже экрана, а граф перехватывал прокрутку страницы.
  Теперь граф на весь экран, фильтры за кнопкой «Фильтры», панель выезжает снизу с крестиком,
  камера держит выбранный узел над панелью; кнопки +/− на тач-экранах скрыты (масштаб щипком).

Это новая мобильная композиция, в кандидате Claude Design её не было (дизайнер отметил,
что «может понадобиться нижняя панель»). Перед переносом в утверждённый дизайн её нужно
согласовать отдельно.
