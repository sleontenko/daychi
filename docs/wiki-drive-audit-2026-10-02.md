## Папки

Из 4 папок метаданные и список прямых дочерних файлов прочитаны для 2,
остальные 2 вернули NOT_FOUND. В двух списках 22 файла: 17 MP3 и 5 PDF.
Один PDF уже присутствует среди 271 file ID; после дедупликации найден
**21 дополнительный файл: 17 MP3 и 4 PDF**. Они ещё не созданы как самостоятельные
карточки и не назначены в редакционные партии.

Таким образом, сейчас подтверждены **244 аудиофайла, 14 MP4 и 7 PDF**
с учётом найденного содержимого папок, без дублей по file ID.
Это не итог всего Drive: 27 отдельных файлов и 2 папки недоступны.
list_folder запрошен с top_k=1000; endpoint не вернул продолжение/общее число,
поэтому полнота списков независимо не доказана. Вложенных папок в ответах нет.
Разные file ID могут содержать одно и то же занятие; дедупликации по содержимому
или между Drive/YouTube/Zoom ещё не было.

## Следующий процесс

1. Аудио M4A/MP3: получить разрешённый файл, проверить фактический формат,
   длительность, хеш, наличие готового текста; затем 16 kHz mono → VAD →
   Turbo/Parakeet → короткие повторы → редактура и независимая проверка.
2. Видео MP4: тот же процесс после извлечения аудио ffmpeg; видеоряд сохранять
   для проверки движений по мере необходимости.
3. PDF: извлечь текст, при необходимости OCR; ASR не применяется.
4. Недоступные файлы/папки: отдельная очередь проверки доступа/актуальности,
   не считать автоматически удалёнными.
5. Стабильная привязка Drive file ID к карточкам и source hashes ещё требует
   адаптера: текущий production импортёр обогащения принимает YouTube ID.

Длительности connector не вернул, несмотря на запрос videoMediaMetadata.
Для бюджетирования аудио нужны реальные duration через подходящий metadata API
или ffprobe после разрешённого получения файлов. По размеру duration не угадывать.
Нового ASR/конспектов/публикации этим аудитом не выполнено; в вики по-прежнему
последний подтверждённый результат 45 материалов и 135 цитат.
