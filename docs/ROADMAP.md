# План развития

Это порядок приоритетов, не обещание сроков. Новые продуктовые решения и выпуск
каждой версии согласуются с владельцем. Выполненные пункты переносятся в журнал
TestFlight с номером сборки и доказательствами проверки.

## 1. Надёжность первого личного релиза — в работе

- [x] Реальное регулярное расписание вместо технического экрана.
- [x] Выбор дат, сохранение и локальные уведомления без кода подключения.
- [x] Визуальный язык принятого прототипа, рабочие основные экраны.
- [x] Проверка Release в симуляторе и доставка тестового уведомления.
- [x] Сборка 3 доступна существующей группе TestFlight.
- [ ] Подтвердить на физическом iPhone: обновление с build 2, мобильная сеть,
  получение реального напоминания, отмена, выключенные разрешения, перезагрузка.
- [ ] Проверить отсутствие сети, смену часового пояса, переход дня и DST.
- [ ] Проверить VoiceOver, крупный шрифт, небольшой экран, Reduce Motion.
- [ ] Разобрать предупреждения зависимостей и отсутствующие сторонние dSYM.

Выход: основной сценарий подтверждён на телефоне; нет блокирующих ошибок.

## 2. Действительно актуальное расписание — запланировано

- Безопасно подключить согласованные Telegram-источники на сервере.
- Различать регулярное расписание, разовую отмену и перенос конкретной даты.
- Сохранять источник и историю каждого изменения, обрабатывать неоднозначность
  с подтверждением человеком, не отменять занятия по догадке.
- Выбрать механизм обновления при закрытом приложении и согласовать переход
  с локальных уведомлений на серверные, если он потребуется.
- Исключить двойные и устаревшие напоминания; проверить мониторинг сервиса,
  восстановление после перезапуска и резервное копирование.

Выход: подтверждённый перенос/отмена корректно меняет выбранное занятие и
напоминание, включая сценарий закрытого приложения. Приватные сообщения и ссылки
не попадают в публичный API или клиентский bundle.

## 3. Удобство личной практики — требует продуктового решения

- Повторяющийся выбор серии занятий вместо ручного выбора каждой даты.
- Индивидуальное время напоминания для занятия, фильтры онлайн/место/практика.
- Синхронизация между устройствами и восстановление после переустановки:
  сначала согласовать необходимость аккаунта и политику хранения данных.

## 4. Учебный продукт — позже

- Подключить реальные материалы к вики и плееру вместо демонстрационных данных.
- Согласовать права доступа, авторизацию и обработку закрытого корпуса.
- Карта практики, заметки и прогресс: определить модель и проверить пользу,
  затем реализовать в принятом визуальном языке.

Внешние тестировщики / App Store, privacy policy, onboarding, поддержка и
