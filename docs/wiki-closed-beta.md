# Вики без входа — закрытая бета, build 7

19 сентября 2026: владелец попросил убрать логин и пароль для небольшой доверенной
группы и сразу выпустить следующую сборку. Полноценная авторизация отложена до
более открытых версий. Публичный API не превращается в анонимную библиотеку.

## Реализация

В закрытый TestFlight binary включён локальный снимок 1145 материалов из индекса.
Каталог, поиск, фильтры, детали и закладки не требуют сети или сессии. Исходные
видео/Zoom/документы по-прежнему открываются внешними ссылками и требуют интернета.
Экран входа и выход не участвуют в рабочем пользовательском сценарии. Макет вики
сохранён. `wiki-login.tsx` остаётся неиспользуемым исходником для будущего этапа.
Сервер build 6 остаётся защищённым и не используется каталогом build 7.

Снимок содержит ссылки/коды исходных материалов и доступен получателям binary;
это временная модель распространения доверенной группе, не защита для публичного
релиза. Не публиковать web export с таким каталогом. До открытого распространения
вернуть серверную авторизацию и убрать каталог из binary.

## Воспроизводимая подготовка

Из корня репозитория, при наличии приватного индекса и существующей базы ID:

```sh
.venv/bin/python scripts/prepare_wiki_beta_catalog.py
```

Генератор использует действующую нормализацию API и временную копию SQLite;
не меняет сессии или базу production. Старые ID материалов и закладки сохраняются.
Выход: `apps/practice-app/src/features/wiki/generated/catalog.json`, права 600,
каталог исключён из Git. Отсутствие файла намеренно блокирует сборку вместо
незаметной подстановки пустого/mock-каталога. Значения логина, пароля, токены
авторизации в binary не встраиваются. Обновление снимка требует новой сборки.

## Проверки

TypeScript, Expo lint, 14 тестов расписания, 2 теста локального поиска и 41
backend-тест прошли. Тест генератора проверяет сохранение ID и отсутствие изменений
живых сессий. Нативная QA и статус Apple фиксируются в журнале выпуска.

## Контекст сетевой ошибки build 6

Пользователь видел «Не удалось подключиться…» и не мог открыть `/health` в Safari.
19 сентября повторная проверка заданного входа прошла как через внутренний адрес,
так и через каждый из трёх публичных IPv4 Funnel relay с проверкой TLS: HTTP 200,
каталог 1145. Это не доказывает доступность с сети пользователя. Причина проблемы
на телефоне не установлена; дальнейшая диагностика отменена владельцем. Build 7
обходит зависимость каталога от сервера, но не объявляет исправленной сеть/Funnel.

Экспорт build 7 помечен `testFlightInternalTestingOnly=true`: эта сборка
предназначена для внутренней группы, не для внешней беты/App Store.

Apple завершила обработку: build 7 имеет статус Testing и назначен существующей
группе «Личное тестирование» (4 тестировщика). Подробности — в журнале TestFlight.
