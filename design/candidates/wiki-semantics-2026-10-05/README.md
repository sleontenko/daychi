# Кандидат: темы, словарь и подтверждённые связи

Статус: **не принят, production не изменён**. Это дополнение опубликованного
Notion / Quartz; оно не заменяет принятый референс.

Референсы: [Notion](../../../docs/qa-wiki-notion-2026-10-01/screenshots/reference-notion.jpg)
и [Quartz](../../../docs/qa-wiki-notion-2026-10-01/screenshots/reference-quartz.jpg).
Парные копии: `screenshots/reference-notion.jpg`, `reference-quartz.jpg`;
runtime ниже использует только синтетические данные.

Сохраняются нейтральный фон, типографика, терракотовые ссылки, боковая навигация,
ширина чтения до 72ch и одноколоночный mobile. Новые элементы: «Темы и словарь»,
страница понятия с источниками, подтверждённые связи в уроке и фильтр графа.
Номера источников — кнопки 44×44 px, прокручивают страницу без замены route hash.

| Вход / состояние | Поведение / выход |
|---|---|
| Навигация → темы и словарь | Список терминов и тем, число источников, метка черновика |
| Недавние → понятие | Обычное название и фактическая дата обновления, без статуса в заголовке |
| Список / прямая ссылка → понятие | Описание с номерами доказательств; перечень материалов, пояснения и цитаты |
| Источник в понятии → урок | Обычный reader; отдельный блок «Темы и понятия» с обратной ссылкой и цитатой |
| Понятие → локальный граф | Выбран узел понятия; соседние материалы, отдельные линии смысловых связей |
| Граф → понятие | «Читать термин/тему и цитаты» возвращает к странице |
| Loading | Текстовый status до ответа API; навигация остаётся доступной |
| Нет страниц / нет совпадений | Явная пустая выдача; доступ к остальным разделам |
| Отсутствует / устарел источник | Страница недоступна, объяснение и ссылка к словарю |
| Ошибка API / нет сети | Сообщение и «Повторить»; после восстановления повтор без перезагрузки |
| Доступ истёк | Существующий login с объяснением; исходный маршрут сохраняется |
| Назад | Существующая история reader/графа, сохранение прокрутки и фильтров |
| Выключен смысловой фильтр | Скрыты semantic nodes/edges; выбранный контекст остаётся в панели, повторное включение восстанавливает граф |

На синтетическом наборе проверены desktop и 390×844: нет горизонтального
переполнения, источник и Back доступны. Нативная safe area/Android Back/WKWebView
не проверялись, binary не выпускался. Нет учительского одобрения содержимого.

Проверка исправила оставшийся узел понятия при отключении смыслового фильтра
в локальном графе и hash-переход вместо прокрутки к цитате. Кандидат использует
существующий reader, без нового визуального языка или вымышленных материалов.
Для выпуска требуется принятие этого UX; [протокол](../../../docs/wiki-semantic-pipeline.md).

Совместимость: новые узлы графа выдаются только при `?semantics=1` и включённом
feature flag. Старые клиенты, включая существующий native binary, получают
прежний граф. Новый веб-клиент запрашивает слой явно; native host пока этого не делает.
