# Cabinet native reader — 17 October candidate

Keep the owner-selected Claude iteration3 reader/graph, phone references and existing
iPad composition. Explicit native content opt-in selects a distinct protected host;
flag-off native and web retain their existing transports. No credential/profile enters
HTML or messages. Cabinet owns sign-in; Zoom retains legacy organizer authority.

| Entry/state | Presentation and transition |
| --- | --- |
| Wiki, signed out | Existing cream typography/button primitives: Wiki, sign-in explanation, account button to existing Cabinet route. No library payload. |
| Checking | Spinner and account-check text; previous protected host destroyed. |
| Active account | Same shared library, graph, structured articles, search and saved IDs; every backend read validates Cabinet. SPA navigation performs a fresh protected category read before showing retained metadata. |
| Missing optional article404 | Existing material summary remains; missing material shows existing not-found state. |
| Invalid credential401 | Destroy protected host and native link state; sign-in gate. Only the matching current credential can be cleared. |
| Blocked403 | Clear content; school restriction text, existing account screen and explicit retry. Retain credential. |
| Offline/deadline/503/rate | Clear content; retry UI, honor Retry-After; no previous article fallback. |
| Retry | Restore account, then remount/reload through authoritative reads. |
| Background/inactive tab | Destroy protected host and in-flight reply lease immediately; retain only bounded navigation metadata in memory for this account. |
| Foreground/tab return | Revalidate account through existing lifecycle, then reload current location. Filters/query/history/scroll remain; no persisted private body. |
| Sign-out/account change | Clear retained location and private host. Existing bookmarks/recent ID keys remain unchanged. |
| External source/recording | Native host re-reads its originating protected DTO and verifies exact current link before opening HTTPS. No arbitrary source URL, credential or Zoom opening. |
| Online class | Separate native sheet using the existing legacy invitation check and Zoom-only projection; Cabinet never grants Zoom. |
| Back/close | Shared native history inside reader; Android Back closes Zoom sheet first, then reader history; account route uses existing Back. |

Paired synthetic reference/runtime phone/iPad captures and runtime behavior checks
are required before acceptance. This candidate does not promote a new reference or
release a binary. The graph library/layout and reader content markup are retained.
